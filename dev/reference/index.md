# Package index

## Word, PowerPoint and HTML

Convert LaTeX equations into ‘Office Open XML Math’, the format of
equations in Word and PowerPoint documents, or into the HTML of ‘KaTeX’.

- [`transform_mathjax()`](https://ardata-fr.github.io/equatags/dev/reference/transform_mathjax.md)
  : 'MathJax' equation as 'HTML' or 'MathML'.

## Size and drawing

Measure equations and draw them with ‘grid’, with the rules of TeX and
an OpenType math font, independently of the graphic device.

- [`equation_size()`](https://ardata-fr.github.io/equatags/dev/reference/equation_size.md)
  : Size of equations
- [`equation_grob()`](https://ardata-fr.github.io/equatags/dev/reference/equation_grob.md)
  : Draw an equation with 'grid'
